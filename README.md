# CFB AI — College Football Intelligence

A polished front-end prototype based on the provided specification.

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

## Important
The included numbers are DEMO/MOCK data for the interface. They are not live sportsbook odds or verified current predictions.

## Production next steps
Connect:
- College football statistics provider
- Sportsbook odds/line-history provider
- Weather API
- News/injury/roster sources
- Persistent database
- Server-side prediction engine
- Scheduled jobs for refresh + postgame evaluation

The UI is intentionally structured so those services can replace the demo data without redesigning the interface.
